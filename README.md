# UTME Drill Lab

React, Express, and libSQL clone of the Test Driller UTME workflow. Palette is indigo, amber, and slate.

Demo login: `ada@example.com` / `Passw0rd!`  
Spare keys: `TD-AMBER-DEMO`, `TD-SLATE-LAB`

## Run locally

```bash
cd server && npm install && npm start
cd client && npm install && npm run dev
```

## Flow

1. Sign in
2. Activate if needed
3. Pick Use of English plus three subjects
4. Exam, practice, or correction
5. Timer, grid, calculator, bookmarks
6. Submit for subject split and correction log
